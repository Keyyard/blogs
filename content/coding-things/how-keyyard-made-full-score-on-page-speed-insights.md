Hey, so recently I was refactoring my website, wanted to push it up a little and yea, here we go.

[![Page Speed Insights Score](/static/coding-things/pss.webp)](https://pagespeed.web.dev/report?url=keyyard.xyz)
[Page Speed Insight Score](https://pagespeed.web.dev/)

1. Don't import things you dont use in a library
2. Use safe image loader
3. use lazy loading for images
4. use skeletons for lazy loading contents
5. use dynamic imports for components
6. optimize your images quality
7. optimize your images size
8. optimize your images format, webp is the best
9. remove unused packages, css, js, fonts, etc
10. using good color abstraction, im using: https://dequeuniversity.com/rules/axe/4.10/color-contrast
11. use good font loading strategy, like preload, or font-display: swap
12. use good font size, not too big, not too small
13. SEO optimization, use good title, description, keywords, etc, read more at [Keyyard Writing Guide](/writing-things/how-keyyard-writes-an-article/)
14. use good meta tags, like og:image, og:title, og:description, etc
15. use good social media sharing tags, like twitter:card, twitter:title, twitter:description, etc
16. use good sitemap, robots.txt, etc
17. use good analytics, like google analytics, or other tools
18. use good performance monitoring tools, like lighthouse, webpagetest, etc
19. use good caching strategy, like browser caching, server caching, etc
20. use good CDN, like cloudflare, or other tools
21. make the website & promote it on your contents, write with it
22. has internal linking, like linking to other articles, pages, etc

and another thing to get the perfect score is, try to analyze it again later. sometimes the score can be due to traffics,..
